# FOURFOLD · 네컷모먼트

촬영 → 네 장 선택 → 프레임·필터·문구 → 이미지 표시 → PNG 다운로드.
서버와 API 키가 필요 없는 정적 웹 앱입니다. 사진은 브라우저 안에서만 처리합니다.

## GitHub Pages에 올리기

1. ZIP을 풀고 **index.html과 나머지 파일들을 GitHub 저장소 루트**에 올립니다. 폴더 안에 한 번 더 넣지 마세요.
2. 저장소의 **Settings → Pages**를 엽니다.
3. **Source: Deploy from a branch**를 선택합니다.
4. **Branch: main**, **Folder: / (root)**로 저장합니다.
5. 배포가 끝나면 제공되는 HTTPS 주소를 휴대폰 Safari 또는 Chrome에서 직접 엽니다.

HTML/CSS/JavaScript를 그대로 제공하므로 npm 설치나 빌드 과정이 없습니다.
모든 파일 경로가 상대 경로여서 사용자 페이지와 프로젝트 페이지 모두 사용할 수 있습니다.

## 파일

- `index.html`: 화면 구조
- `styles.css`: 모바일·데스크톱 스타일
- `app.mjs`: 촬영, 파일 선택, 편집 상태, 다운로드
- `core.mjs`: 템플릿 20종·프레임·필터 정의, 자르기와 배치 계산
- `renderer.mjs`: 미리보기·완성 이미지 공통 합성
- `sample.jpg`: AI로 생성한 미리보기 예시 사진
- `.nojekyll`: 정적 파일 직접 제공 설정

## 템플릿

세로형 8종(클래식·라운드·필름롤·티켓·미니멀·도트·스트라이프·다이애고널),
정사각형 계열 10종(그리드·보더리스·윈도우·폴라로이드·오버랩·아치·더블·모자이크·매거진·하프),
가로형 2종(포스트카드·가로배너)입니다. 모든 템플릿은 사진 네 장을 사용하며 프레임 색·필터와 자유롭게 조합됩니다.
좌표는 `core.mjs`에 "가로 폭 = 1" 비율로 정의되어 있어 값을 추가하면 템플릿이 늘어납니다.

## 사용하기

- 카메라를 허용하고 3·5·10초 간격으로 4장 또는 8장을 찍습니다.
- 또는 앨범 사진을 최대 8장까지 불러옵니다. 사진당 20MB, 48MP 이하를 지원합니다.
- 처음 네 장이 자동 선택됩니다. 선택한 사진을 다시 누르면 해제됩니다.
- 선택한 썸네일의 좌우 버튼으로 순서를 변경합니다.
- 템플릿 20종(세로 스트립·2×2 그리드·폴라로이드·가로 배너 등), 프레임 10색, 필터 5종, 문구, 날짜 표시를 선택합니다.
- **이미지 완성하기**를 누르면 실제 완성 이미지와 다운로드 버튼이 나타납니다.
- PNG로 저장합니다. 템플릿 비율에 맞춰 약 430만 화소(클래식은 1200×3600)로 내보냅니다. 출력 해상도가 원본 디테일을 추가하지는 않습니다.

## 휴대폰에서 확인할 점

- 카메라는 HTTPS 접속과 사용자 권한이 필요합니다. 메신저 안의 브라우저에서 안 되면 Safari·Chrome으로 직접 열어주세요.
- iPhone에서 다운로드가 사진첩 대신 파일 앱에 저장될 수 있습니다. 완성 이미지를 길게 눌러 저장하거나 파일 앱에서 사진으로 저장하세요.
- 브라우저에서 열리지 않는 HEIC 사진 등은 JPG·PNG로 변환한 뒤 불러옵니다.
- 화면 잠금이나 앱 전환 시 촬영을 중단합니다. 이미 촬영한 사진은 현재 페이지에 남습니다.
- 새로고침하거나 탭을 닫으면 작업이 사라집니다. 완성본을 먼저 다운로드하세요.
- 예시 사진은 사용자의 완성 이미지에 포함되지 않습니다.

## 확인한 범위

자르기, 필터 픽셀, 네 장 순서, 프레임 색상, 템플릿 20종의 미리보기·PNG 합성을 Chrome에서 검사했습니다.
실제 iPhone·Android 카메라와 저장 흐름은 기기별 확인이 필요합니다.
선택적 WebMCP 인터페이스는 지원 브라우저에서만 동작하며 실행 검증은 하지 못했습니다.

## PC에서 실행

ZIP을 푼 디렉터리에서:

```sh
python3 -m http.server 8000
```

PC에서 `http://localhost:8000`을 엽니다. 휴대폰에서 PC의 HTTP IP 주소로 접속하면 카메라가 제한되므로 휴대폰은 배포된 HTTPS 주소를 사용하세요.
